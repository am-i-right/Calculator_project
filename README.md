# Java Console Calculator

A simple and robust calculator built with Java. It performs basic arithmetic operations and remembers the result for continuous calculations.

## Features
- Basic operations: addition (+), subtraction (-), multiplication (*), division (/)
- Continuous calculation mode (the result becomes the first number for the next step)
- Safe division (protects against division by zero)
- Control commands: type **C** to clear/reset, **S** to exit (case-insensitive)
- Input validation (prevents crashes if you type letters instead of numbers)

## How to Run

1. Make sure you have **Java (JDK)** installed on your computer.
2. Open your terminal or command prompt.
3. Navigate to the folder containing `Calculator.java`.
4. Compile the code:
   ```bash
   javac Calculator.java
   ```
5. Run the program:
   ```bash
   java Calculator
   ```
